# Security policy

WarrantX contracts are pre-audit software intended for testnet evaluation. Do not use the current release to custody material mainnet funds.

Report vulnerabilities privately through GitHub's **Security > Report a vulnerability** flow. Include the affected commit, impact, reproduction steps, and suggested mitigation. Do not disclose an unpatched vulnerability in a public issue.

Maintainers will acknowledge a complete report within five business days and coordinate a fix and disclosure timeline.
